# 이력서

정적 HTML/CSS/JS로 만든 이력서 페이지입니다. 빌드 과정과 외부 의존성이 없습니다.

- `index.html` — 내용
- `assets/style.css` — 디자인(라이트/다크 자동, A4 인쇄용 `@media print`)
- `assets/main.js` — 인쇄 버튼

## 미리보기

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

## 배포

GitHub Pages에서 소스를 `master` 브랜치의 `/ (root)`로 지정합니다.
